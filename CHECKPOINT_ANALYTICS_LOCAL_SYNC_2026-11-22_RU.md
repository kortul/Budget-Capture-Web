# Контрольная точка — Financial Analytics и локальная синхронизация
Дата: 22 ноября 2026
Ветка: `main`
Версия приложения: `0.1.6.0`

## Автозагрузка базы в Analytics

- Добавлен `shared-database.js`: хранит активную копию SQLite в IndexedDB браузера.
- Основное приложение синхронизирует базу после открытия/создания и после сохранения.
- Открытие базы теперь ожидает завершения первичной локальной синхронизации.
- Numbers Import синхронизирует базу после импорта и после скачивания обновлённого `.budget`.
- Analytics автоматически читает локальную копию при открытии страницы.
- Уже открытая вкладка Analytics получает BroadcastChannel-событие и перечитывает базу; также проверяет обновление при возвращении во вкладку.
- Данные не передаются на GitHub Pages или внешние серверы. Копия локальна для этого браузера и устройства. При очистке данных сайта IndexedDB-копию потребуется создать заново, открыв базу в основном приложении.

## Что есть в русской Analytics

- Годовой фильтр, карточки доходов/расходов/баланса/доли сбережений.
- Месячные поступления, расходы и баланс; выбранный год дополняется нулевыми месяцами.
- Специальные вводы/выводы отдельно от обычного Net.
- Расходы на жизнь: категории, доли, средние суммы и помесячная детализация.
- Расходы Саши с отдельной настраиваемой долей общих категорий кафе/такси (по умолчанию 75%).
- Работа, магазин и кредиты: сводки по категориям, месяцам и годам.
- Группы категорий настраиваются в разделе «Настройка состава отчётов». Эти настройки остаются в локальном хранилище браузера, не изменяя транзакции и файл `.budget`.

## Личные ручные сводки Numbers

- Личные исторические суммы не должны находиться в публичном HTML/JS репозитория.
- Для них добавлен локальный импорт JSON через блок «Сводки из старой таблицы Numbers».
- После выбора JSON его содержимое сохраняется в IndexedDB под ключом `analytics-manual-reference-v1`.
- JSON-файл с данными нужно хранить отдельно от Git-репозитория. Не добавлять его в GitHub и не публиковать вместе с приложением.
- В UI сохранены предупреждения, если месячные/годовые значения не сходятся с итогами исходной таблицы. Годовые заголовки, которые отсутствовали в исходнике, не додумываются.

## Действия после обновления

1. Обновить Pages через Ctrl+F5.
2. Один раз открыть актуальный `.budget` в основном приложении — Analytics получит локальную копию.
3. Открыть Analytics; повторно выбирать базу не нужно.
4. Один раз загрузить отдельный личный JSON со сводками Numbers, чтобы они появились в ручном разделе.
